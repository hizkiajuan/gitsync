# Changelog

### Features

- Menu bar panel that shows which Git working trees need a push, pull, or
  upstream fix, grouped by computer, with a Sync health summary.
- Recursive discovery of working trees under selected local folders and SSH
  computers, with cancel and progress.
- Consent-based, upstream-only fetch; read-only status checks that never take
  `index.lock`.
- Settings for check interval, wake refresh, notifications, launch at login,
  appearance, Git executable, and timeouts.
- Sanitized diagnostics, bounded logs, and a reset that never touches
  repositories.
